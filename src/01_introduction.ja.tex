\section{背景}
\subsection{RANとCoreの密結合による進化の硬直性}
モバイル通信システムは，無線アクセスネットワーク（RAN）とコアネットワーク（Core）が密接に結合したアーキテクチャを採用してきた．この密結合性は，通信品質の保証や移動管理の効率化に寄与してきた一方で，システム全体の進化を硬直化させる要因ともなっている．特に，RAN側の物理的な制約（ハードウェア更新の困難さ）が，ソフトウェアベースで急速に進化するCore側の新機能導入を阻害するケースが増えている．

\subsection{NTN等のレガシー環境における課題}
近年注目される非地上系ネットワーク（NTN: Non-Terrestrial Network）やIoT向けネットワークでは，衛星やHAPS（成層圏プラットフォーム）などの物理インフラが一度打ち上げられるとハードウェア更新が極めて困難である．これらのシステムは多くの場合，LTE/EPC（4G）ベースで構築されているが，地上のモバイル網が5G/6Gへと移行する中で，Core側のサポート終了や新機能（スライシング等）への対応が課題となっている．物理層を変更せずに，論理的な収容先を次世代Coreへ移行させる技術が求められている．

\section{問題意識と課題}
本研究の背景には，以下の問題意識がある．

\begin{itemize}
\item \textbf{物理更新の困難さとソフトウェア進化のギャップ}: NTNや既存のプライベートLTE環境では，RANの物理的な更新がコストや運用面で困難である一方，Core側はクラウドネイティブ化により頻繁なアップデートが可能となっている．この速度差を吸収する仕組みが欠如している．

\item \textbf{異世代間相互接続の未確立}: 4G RANを5G Coreに収容するための標準的なインターフェース（N26等）は存在するが，これはCore間の連携を前提としており，RANとCoreを直接異世代接続する手法は確立されていない．

\item \textbf{実機検証の不足}: シミュレーションによる検証は行われているが，実機RAN（sXGP等）を用いた異世代相互接続の実証例は少なく，実用的な性能やオーバーヘッドの評価が不足している．
\end{itemize}

\section{研究目的}
本研究の目的は以下の通りである．
\begin{itemize}
\item 物理的に更新困難なレガシーRANを，ハードウェア変更なしに次世代Coreに収容する「疎結合アーキテクチャ」を提案する．
\item 提案アーキテクチャに基づく「S1-N2変換ゲートウェイ」を設計・実装し，4G RANと5G Coreの異世代相互接続を実証する．
\item 実機検証を通じて，提案手法が実用的な性能（スループット・遅延）を有することを確認する．
\end{itemize}

\section{問題意識と課題}
本研究の背景には，以下の問題意識がある．

\begin{itemize}
	\item \textbf{実装検証環境の不足}: モバイルコアはソフトウェア化が進み，OSSも充実してきたが，実機RANを用いた検証環境は電波法上の制約から構築が難しい．シミュレータでは発見困難な実機特有の課題（タイミング問題，リソース競合，プロトコル解釈の相違，実装依存の挙動など）を早期に検出できる環境が求められている．

	\item \textbf{異世代間相互運用の実装課題}: 4G RANと5GC間のプロトコル変換には，仕様書で明示されていない実装判断が多数存在する．手順の分離方法，エラーハンドリング，パラメータマッピングなど，実装者が直面する具体的な課題とその解決策を体系化する必要がある．

	\item \textbf{再現可能な検証基盤の欠如}: 相互運用性の検証には，環境構築が容易で，第三者が再現できる実験基盤が重要である．Docker化や詳細な手順書により，研究・教育コミュニティで共有可能な検証環境を整備する必要がある．
\end{itemize}

これらの課題を踏まえ，本研究ではsXGPを活用した実機検証環境を構築し，4G-5G相互接続における実装レベルの課題を明らかにする．

\section{研究目的}
本研究の目的は以下の通りである．
\begin{itemize}
	\item 4G RANと5GC間の相互運用性を実現するプロトコル変換層の設計・実装
	\item 実機検証を通じた実装レベルの課題の発見と分類
	\item 異世代間プロトコル変換における設計指針の提示
	\item 再現可能な検証環境の構築と検証手順の体系化
\end{itemize}

\section{本論文の貢献}
本論文の主要な貢献は以下の通りである．
\begin{itemize}
	\item \textbf{世代不変性に基づく疎結合アーキテクチャの理論化と実証}: モバイル通信の根幹機能（AAA，Registration Management，QoS）が世代を超えて不変であることに着目し，これらを抽象化してマッピングすることで，RANとCoreの依存関係を排除できることを理論的かつ実験的に示した．

	\item \textbf{新しい移行モデルの提示}: 従来の一斉更新（ビッグバン移行）やCore間連携（N26）に依存せず，RANの物理更新を伴わずにCoreのみを先行して次世代化する柔軟な移行モデルを提示した．

	\item \textbf{実用的インパクトの創出}:
	\begin{itemize}
		\item \textbf{R\&D}: 既存のLTE設備を再利用した安価な次世代Core検証環境の構築手法を確立した．
		\item \textbf{商用展開}: 既存RAN資産を活かしたまま，Core側の新機能（スライシング等）を段階的に導入する戦略を可能にした．
		\item \textbf{NTN/IoT}: 物理的に更新不可能なインフラ（衛星等）の延命と機能拡張への道筋を示した．
	\end{itemize}
\end{itemize}
