\small
Mobile core networks increasingly rely on software-defined implementations, yet hands-on experiments with real radio access remain challenging due to spectrum licensing constraints and costly equipment. This study addresses the practical difficulty of validating cross-generation protocol interworking between legacy LTE RAN and 5G Core without modifying deployed base stations or user devices.

We design and implement a protocol conversion layer that bridges S1AP/S1-U (LTE) and NGAP/N3 (5G) interfaces, maintaining NAS transparency while explicitly separating Initial Context Setup from PDU Session procedures. Using sXGP—a TD-LTE profile operable in Japan's unlicensed spectrum—combined with commercial smartphones and Open5GS, we demonstrate stable Registration and PDU Session establishment under real radio conditions.

Through iterative real-hardware testing, we identify and document implementation-level challenges that simulators fail to expose: timing sensitivities, protocol interpretation ambiguities, and implementation-dependent behaviors across control and user planes. These findings are systematically classified into reusable design patterns for TEID management, NAS conversion strategies, QoS mapping, and error handling.

Beyond basic call establishment, our test suite covers Protocol Configuration Options (DNS, MTU), QoS differentiation (5QI/QFI mapping), UL-CL local breakout, IPv6-only operation with NAT64/DNS64/464XLAT, DSCP/ECN preservation, and GTP-U path MTU handling—providing a regression baseline for interoperability validation.

For IoT-NTN migration scenarios currently dependent on EPC, this platform enables early 5GC readiness assessment under high-latency satellite conditions. By packaging the environment with Docker and documenting all artifacts, we lower the barrier for collaborative research and offer practical reference material for system implementers.

Our contributions include: (1) a functional protocol conversion layer with documented design choices, (2) a catalog of discovered implementation challenges with reproduction steps, (3) systematized design guidelines for cross-generation interworking, and (4) a reproducible testbed combining license-free spectrum compliance with real-hardware validation.
